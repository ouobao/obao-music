# 欧包音乐 · 视觉重设计（Studio）

> 日期：2026-10-22 ~ 2026-10-23
> 起因：用户反馈"整个 UI 设计和布局 色彩 还是很烂 很浓的 AI 味 根本不像一个有着丰富经验的产品团队设计出来的 APP"

---

## 0. 诊断：所谓的"AI 味"到底是什么

动手之前先定位。通读旧设计令牌后，问题非常集中 —— 旧体系叫"Stage v4 / 舞台"，它的三条核心设定本身就是 AI 生成界面的典型配方：

| 旧设定 | 为什么是"AI 味" |
| --- | --- |
| 粉紫渐变主色（`#fb3b60` → `#8b5cf6`） | AI 生成 UI 的默认配色，饱和度高、色相跨度大 |
| 全幅模糊封面铺底 + 三团极光光斑 + 颗粒 | "让界面被专辑照亮"听起来高级，实际是给整个窗口蒙一层彩色雾 |
| 一切外壳都是悬浮玻璃卡片（圆角 26–32px + 发光投影 + backdrop-blur） | 无差别地把所有容器做成"漂浮的发光圆角卡"，是最易识别的 AI 特征 |
| 大量 `translateY(-2px) scale(1.02)` 悬停 | 位移弹跳式微交互，对桌面应用是噪音 |
| 38–46px 的展示级标题 + 全大写表头 + 0.12em 字距 | 用夸张字阶制造"高级感"，反而压垮信息层级 |

**结论：不是某个页面做得不好，是设计语言本身选错了。**

---

## 1. 新体系：Studio

反向重构，五条原则：

1. **界面是背景，封面是主角。** 删除极光、删除模糊封面铺底。界面本身不产生任何装饰色，颜色只来自专辑封面。
2. **中性优先。** 整套 UI 只用暖中性灰阶。强调 = 明度差，不是色相差。
3. **扁平。** 外壳是贴边面板 + 1px 发丝分隔线。不做悬浮玻璃、不做 backdrop-blur、不做发光投影。阴影只给真正浮起的层。
4. **紧凑几何。** 圆角 4/6/8/10/12，删除 20–32px 大圆角。
5. **字阶克制。** 页面标题 28px、区块 17px、正文 14px，靠字重与留白建立层级。

### 色板

| | 深色 Graphite | 浅色 Paper |
| --- | --- | --- |
| 画布 | `#0b0b0c` | `#f6f5f2` |
| 外壳 | `#0e0e0f` | `#fbfaf8` |
| 表面 1 / 2 / 3 | `#151517` / `#1b1b1e` / `#232327` | `#fbfaf8` / `#f1f0ec` / `#e8e7e2` |
| 主文字 | `#f2f1ee` | `#171614` |
| 强调 | `#f2f1ee`（近白） | `#171614`（近黑） |

强调色不再是彩色 —— 深色主题下"高亮"就是比正文更亮，浅色主题下就是更黑。整站因此做到**零彩色**。

## 2. 具体改动

### 外壳几何：从"悬浮卡"到"贴边面板"

| | 旧 | 新 |
| --- | --- | --- |
| 侧栏 | `top:58px left:14px bottom:114px`，圆角 26px，四周投影 + 模糊 | `inset:0 auto 0 0`，贴边，右侧 1px 分隔线 |
| 顶栏 | 透明覆盖层 + 渐变遮罩，按钮悬浮 | `fixed` 平面条，左侧让开侧栏，底部 1px 分隔线 |
| 播放坞 | 底部悬浮圆角卡，四周留 14px | 通栏贴底，顶边 1px 分隔线 |
| 极光/模糊封面/颗粒 | 三层装饰 | 全部 `display:none`（DOM 结构保留，视觉与合成层均已移除） |

### 导航

- 激活态：整颗**渐变实心胶囊** → **中性填充 + 左侧 2px 指示条**
- 行高 44 → 38px，图标 28 → 26px，圆角 12 → 6px
- 删除 hover 时的 `scale(1.04)`

### 按钮体系

| | 旧 | 新 |
| --- | --- | --- |
| 主按钮 | 粉紫渐变 + 发光 + 胶囊 | 中性反色实心 + 6px 圆角 |
| 次按钮 | 白玻璃 + 描边 | 透明 + 1px 描边 |
| hover | `translateY(-2px) scale(1.02)` + 增亮 | 只改背景色 |

主播放键：54px 渐变发光圆 → 44px 中性实心圆。

### Hero（全站改动最大的单点）

旧版是"整块模糊封面铺底 + 渐变压暗"的广告牌，会随封面变成一大片彩色玻璃卡。

新版是**编辑式页头**：168px 封面作为视觉锚点，右侧标题 / 元信息 / 操作，中性面板底。删除了 `.hero-backdrop`、`.hero-scrim`、`data-tone-only` 兜底渐变。

### 卡片

- 封面圆角 20 → 6px，删除 `inset 0 0 0 1px white` 假高光
- hover：`translateY(-4px)` + 放大 1.03 + 大阴影 → 仅暗化 28%
- 卡片悬停播放钮：品牌色渐变 → 深色半透明圆 + 白色三角
- 网格 `align-items: stretch`，修复"标题折两行时作者名不对齐"

### 其他真实缺陷

| 问题 | 说明 |
| --- | --- |
| `.hero-desc` 硬编码 `rgba(255,255,255,0.78)` | 假设 Hero 是深色，浅色主题下白底白字几乎不可读 → 改 `--text-secondary` |
| 表头 `text-transform: uppercase` | 中文没有大小写，只会让英文表头突然跳成大写，已删除 |
| `.chart-card-rank` 用 `blur(10px)` | 封面颜色不定，毛玻璃底反而降低可读性 → 实色底 |
| `.dialog-icon--warning/danger/info` 三套渐变 + 彩色投影 | → 淡色底 + 语义色 |
| 歌词页三团 420–480px `blur(70px)` 光球 | 浅色主题下变成右下角粉紫色雾 → 全部删除 |
| 二维码外框 18px 大投影 + 光环 | → `inset 0 0 0 1px` 描边 |
| 抽屉遮罩 `blur(14px)` | 整页糊成毛玻璃 → 纯半透明遮罩 |
| 进度条 hover `height: 6px → 9px` | 高度跳变让播放坞抖动 → 只改底色 |
| 搜索下拉无 `max-height` | 加 `min(70vh, 560px)` 兜底 |

### 应用图标

旧的 `logo5.png` 是橙→粉→紫高饱和渐变 + 浮雕 3D 音符，是全站最直观的"AI 生成"信号。

新建 `assets/branding/obao-mark.svg`：**双八分音符，单色，几何，无渐变无浮雕**。应用于侧栏和登录弹窗。

## 4. 有一个必须说明的点

排行榜页面上仍有紫、绿、青、粉、蓝的卡片封面。这些**不是界面样式**：实测 `<img>` 的 `naturalWidth` 为 800–1024，是从 `p2.music.126.net` 正常加载的**网易云官方榜单封面图**。

要让那一页也完全中性，只能替换平台官方封面，那会丢失榜单识别度。**这是内容，不是设计。**

## 7. 第三轮：顶栏点击 BUG + 登录态

用户反馈：「顶部栏边框貌似拖动区域覆盖了顶部的元素，导致很多顶部的按钮只有下半部分能够点击」。这是**功能性缺陷**，优先级最高。

### 顶栏拖拽区吞掉点击（已修复并实测验证）

**原因**：`.titlebar-drag` 是一条 `position:absolute; top:0; left:0; right:0; height:32px` 的元素，而顶栏高 56px —— 它正好盖住顶栏**上半部分**的所有按钮。

关键在于 Chrome 的 `elementFromPoint` **测不出这个问题**：`-webkit-app-region: drag` 在 Electron 原生层拦截鼠标，DOM 命中测试完全正常。所以最初用 DOM 探测时"全部按钮都能点"，但实际点击无反应。

**修复**（三层保险）：

| 层 | 改动 |
| --- | --- |
| `.titlebar-drag` | 32px → **8px**；`left: 0` → `left: var(--stage-left)`（不盖侧栏）；加 `pointer-events: none` |
| `.topbar` | **移除** `-webkit-app-region: drag`（父级声明会覆盖子级 no-drag） |
| 顶栏子元素 | 显式列出 `button / a / input / [role=button] / .provider-toggle / .search-input-wrapper / .user-profile-badge / .window-controls` 为 `no-drag` |

**验证**：真实鼠标事件点击用户头像 → 登录弹窗成功打开（修复前无反应）。逐控件追踪 `app-region`，6 个控件的最近声明全部为 `no-drag`。

### 登录态界面（首次验证）

用户完成 QQ 音乐 + 网易云登录后，首次看到登录后界面：

- 顶栏显示头像 + 用户名「阿包充满智慧」
- 侧栏 8 个歌单，按「我喜欢 / 我创建的 / 我收藏的」分组
- 首页出现「历史日推」「每日推荐」

期间修掉：

| 问题 | 处理 |
| --- | --- |
| 账号弹窗的「播放授权完整」是绿色实心胶囊，在全中性界面里像彩色贴纸 | 改中性底 + 语义色描边与文字 |
| 歌单列表 `scrollHeight 520 > clientHeight 515`，最后一项被裁 5px，且滚动条隐藏无任何提示 | 加底部 18px 渐隐；滚到底时由 `Sidebar.tsx` 摘掉渐隐类 |

**验证**：`atEnd` 初始为 `false`（有渐隐），滚到底后变 `true`（`mask: none`）。

### 说明

侧栏那 4 个显示为「J」「3」「2」「1」的歌单，经查是**用户自建歌单的真实标题**（`title` 属性一致），不是渲染 bug，未改动。

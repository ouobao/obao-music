## 1. 全局设计语言与视觉规范升级建议

### 1.1 痛点分析
* **层级与反差不够分明**：部分卡片背景（`rgba(255,255,255,0.045)`）与页面底色过于接近，在不同显示器（尤其 TN 屏或非广色域屏）上缺乏立体感与边界感。
* **暗黑模式灰阶单调**：当前纯黑/灰黑偏冷，缺少 Apple Music 般的 **“流体光晕 (Fluid Ambient Aura)”** 与 **“动态自适应色”**。
* **排版信息密度过载**：列表表头、标签、状态指示器在小窗口下有挤压现象，字体层级和字重对比需进一步微调。

### 1.2 升级规范
1. **多重层次毛玻璃 (Aether Translucency)**
   * 底层容器采用 `backdrop-filter: blur(32px) saturate(180%)`，并叠加 `0 0 0 1px rgba(255,255,255,0.08) inset` 的内描边微光，打造高级铝合金/悬浮玻璃质感。
2. **主题自适应流体色彩 (Dynamic Color Accent)**
   * 根据当前正在播放的专辑封面提取的主色调（Palette Dominant），动态柔和投射在左下角/顶栏/歌词背景，营造“声音与色彩共鸣”的氛围。
3. **8-Point 节奏网格与黄金圆角律**
   * 大容器（弹窗/抽屉/页面区块）：`20px` / `24px` 圆角；
   * 媒体卡片与封面：`12px` / `14px` 圆角；
   * 交互胶囊与按钮：`9999px` Pill 药丸形状；
   * 列表项与小型菜单：`8px` 圆角。

## 3. 核心组件精细化美化方案

### 3.1 底部播放栏 (PlayerBar) —— 听歌核心枢纽
* **进度条 (Waveform/Glow Slider)**：
  * 平常为 `3px` 纤细质感，鼠标悬浮时展开为 `6px`，带随进度移动的微发光小游标与时间气泡（Tooltip）。
  * 增加已缓冲区域的半透明区分与波形/平滑渐变效果。
* **封面律动徽章**：
  * 播放状态下封面呼吸微缩（微动效 `scale(1.02)`），暂停时柔和降速回弹。
* **音量与音质胶囊**：
  * 将“无损/高解析度”音质标签做成金属/高亮胶囊，悬浮可呼出快捷切换面板。

### 3.2 播放队列与相似歌曲抽屉 (Queue & Similar Panels)
* **抽屉滑出与阴影**：
  * 采用右侧悬浮浮窗（Floating Drawer）而非贴边生硬面板，四周留出 `16px` 间隙，配合 `var(--shadow-float)`，形成真正的现代悬浮卡片感。
* **正在播放项的高亮识别**：
  * 在当前播放歌曲左侧增加 **三柱律动跳动音频条 (Equalizer Visualizer)**，视觉焦点极佳。

### 3.3 侧边栏与顶栏 (Sidebar & TopBar)
* **导航选中指示条**：
  * 采用平滑移动的 **滑动胶囊背板 (Sliding Active Pill)**，切换路由时背景块平滑滑动到目标 Tab。
* **顶栏窗口控件一体化**：
  * 与 Windows/macOS 原生窗口控制按钮更深度融合，搜索框在激活时轻柔放大，展开悬浮搜索热词浮层。

## 4. 动画交互 (Micro-interactions) 与转场优化

### 4.1 核心动画曲线与原则
* **严禁过度弹簧与长时间眩晕**：统一采用 **Apple-Tier 减速曲线** `cubic-bezier(0.16, 1, 0.3, 1)`。
* **微交互响应 (150ms ~ 180ms)**：按键点击时轻微按下反馈 `transform: scale(0.96)`，悬浮时 `transform: translateY(-2px)` 与光晕淡入。
* **页面平滑推进 (Shared Element Transition)**：
  * 点击卡片进入详情页时，封面从小卡片平滑放大成为详情页 Hero 封面；
  * 点击底部播放栏封面展开歌词页时，封面具有无缝平滑位移过渡。

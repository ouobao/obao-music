# 欧包音乐 · 统一 UI 设计系统（Stage v4「舞台」）

> 样式入口：`src/renderer/styles/tokens.css` → `components.css` → `views.css` → `lyrics.css` → `global.css`
> 关键组件：`components/CoverImage.tsx`（统一封面）、`components/SongShelf.tsx`（横向货架）、`components/MediaCards.tsx`（卡片与区块头）

## 1. 设计概念：把窗口当作舞台

- **全幅画布**：`App.tsx` 取当前封面的调色，写入 `--aurora-a/b`（经 `toAuroraColor()` 规范到可发光区间）
  与 `--ambient-art`（封面整幅模糊铺底）；`.app-ambient` 在其上叠加三团极光光斑与一层颗粒。
- **一切悬浮**：侧边栏、播放栏、顶部控制条、抽屉、弹窗都是**圆角悬浮玻璃卡**（inset + radius + 玻璃 + 大投影），
  没有任何元素贴边。
  - 侧边栏：`left: 14px / width: 258px / top: 58px / bottom: 114px`，圆角 26px
  - 播放坞：`left/right/bottom: 14px / height: 86px`，圆角 26px，内含封面侧光晕
  - 顶栏：`height: 66px`，**透明**（`pointer-events: none`，仅胶囊簇接收事件），内容从下方滚过并柔和淡出
  - 舞台：`.main-content` 绝对定位在 `--stage-left` 与 `--stage-bottom` 之间滚动
- **拖拽**：窗口拖动由真实元素 `.titlebar-drag`（顶部 32px）承担，避免与胶囊簇抢事件。

## 4. 数据驱动的健壮性（接口数据到达后的尺寸与状态）

- **封面**：全部走 `CoverImage` —— 网易云封面按展示尺寸降采样（`?param=WxH`），缓存命中补 `complete` 检查，
  加载失败/无地址回退为 `coverTone` 渐变 + 音符占位（不出现破图图标）。
- **固定比例/行高**：卡片 `aspect-ratio: 1/1`；列表封面固定 46px；时间列与统计数字等宽；
  卡片标题预留两行，避免"标题一行/两行"造成网格参差。
- **长文本**：歌曲名/歌手/专辑/卡片标题/榜名单行或两行截断；Hero 标题两行截断、简介可展开（收起高度按行高精确计算）。
- **状态齐备**：骨架块（脉冲 + 流光）、空状态（图标 + 标题 + 描述 + 动作）、顶部 2px 非阻塞进度条、
  悬停/按下/禁用/加载（`mini-spinner`）齐全。

## 5. 动效

- 视图切换 `viewEnter` 520ms（位移 20px + 模糊消散）；区块 `contentFadeIn`；列表/网格/货架 `itemBlurIn` 按 `--i` 交错 24–34ms。
- 悬停：卡片上浮 8px、货架 7px、行内按钮淡入、图标缩放 1.06–1.10；按下统一 `scale(0.92–0.98)`。
- 悬浮外壳：主题切换 300ms；侧边栏折叠 `--rail-width` 520ms（舞台左边界同步过渡）。
- 全部动效在 `[data-reduce-effects='true']` 下关闭或降级（连 blur 一并去掉）。

## 6. 维护约束

- 新增样式必须使用令牌（颜色 / 圆角 / 时长 / 阴影），禁止写死视觉数值。
- 悬浮层新增元素时必须确认：不遮挡 `.titlebar-drag` 的拖拽区、不压住播放坞、在 960×680 下仍可用。
- 歌词页样式独立在 `styles/lyrics.css`，与外壳共享同一套令牌。

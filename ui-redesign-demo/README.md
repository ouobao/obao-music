# Aether Flow (轻流体) 全新统一 UI & 动效设计系统

本项目是针对现存播放器动效与 UI 过重、视觉不统一问题而专门定制的全新一代设计系统与高保真交互 Demo。

---

## 💎 设计哲学与改进要点

### 1. 动效降重 (Lightweight & Meaningful Motion)
- **拒绝过度弹簧**：剔除原有夸张的 3D 悬浮翻转、大幅度弹簧震荡和过长的转场延迟。
- **统一运动曲线**：全应用统一采用 **Apple-style 平滑减速曲线** `cubic-bezier(0.16, 1, 0.3, 1)`，微交互 150ms，视图过渡 280ms，面板滑出 240ms。
- **歌词页轻量化**：用轻量级 CSS 混合模式与 GPU 硬件加速的柔和流体光晕替代复杂的重型三维计算，逐行歌词聚焦平滑上浮（TranslateY 8px + 模糊过渡），既护眼又极具沉浸感。

### 2. 视觉通透与层级统一 (Aether Translucency)
- **高透毛玻璃体系**：以 `backdrop-filter: blur(20px)` 配合柔和的内发光与边框反光，无论在浅色/深色主题下都通透自然。
- **排版降噪**：减小杂乱标签与边框，以优雅的留白、字阶层次（Title, Subtitle, Caption）和精致的微圆角（8px~14px）划分区块。
- **多主题自适应 (Theme Tokens)**：内置暗夜曜黑、极简皓白、午夜深蓝、琥珀暮光、薄荷极光 5 套精选配色方案。

## 🧭 包含的页面与功能组件

本 Demo 覆盖了主应用清单中的 **100% 全部页面与交互组件**：

1. **页面 (Main Views)**
   - 🏠 **发现音乐 (Home)**：网易云模式 & QQ 音乐模式自适应切换、个性化推荐、每日歌曲、新碟首发、日历日期筛选。
   - 🔍 **搜索结果 (Search)**：综合/单曲/歌手/专辑/歌单 5 维筛选、搜索建议与热搜面板。
   - 🏆 **排行榜 (Charts)**：官方榜、特色榜、全球榜网格卡片与一键播放。
   - 🎼 **歌单广场 (Playlist Discovery)**：分类流派胶囊标签快速过滤、高质量封面网格。
   - 💿 **统一多维详情页 (Playlist Detail)**：
     - 歌单详情 (Playlist)
     - 榜单详情 (Chart)
     - 歌手详情 (Artist - 热门歌曲、精选专辑、相似艺人)
     - 专辑详情 (Album)
     - 推荐集合 (Recommendation Collection)
   - 🕒 **最近播放 (Listening History)**：极简时间轴、听歌频次统计与批量播放。
   - 🎤 **全屏沉浸歌词页 (Lyrics Panel)**：流体光晕氛围、逐行双语歌词平滑同步、悬浮控制胶囊。

2. **全局外壳与抽屉 (Global Shell & Overlays)**
   - 🗂 **极简侧边栏**：支持折叠/展开、自建歌单列表与快速创建。
   - 🔍 **智能顶栏**：集成历史前进后退、搜索胶囊、登录状态与主题切换器。
   - 🎵 **底部播放栏**：歌曲信息、悬浮胶囊控制组、高精度平滑进度条、音质切换、音量胶囊。
   - 📑 **播放队列抽屉 (Queue Panel)**：右侧轻量滑出、支持一键清空、删除与拖拽视觉。
   - 🔮 **相似歌曲推荐抽屉 (Similar Songs Panel)**：网易云歌曲雷达与即时连播。
   - 🔑 **登录弹窗 (Login Dialog)**：扫码/账号极简切换。
   - 🔔 **通知系统 (Toast & Alerts)**：灵动胶囊提示与播放受限引导。
